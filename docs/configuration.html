Configuration

The small runtime surface that controls where Warden listens, what its file APIs can reach and how sessions are transported.

Runtime options

Option / variableDefaultPurpose
--listen / WARDEN_LISTEN127.0.0.1:8080HTTP listen address.
--root / WARDEN_FILE_ROOT/Explorer/Editor filesystem root. Does not sandbox terminal.
--static / WARDEN_STATIC_DIRpublicNift-built frontend directory.
WARDEN_PASSWORD_HASHrequiredPBKDF2 password verifier generated by hash-password.
WARDEN_SECURE_COOKIESautoDefaults false for loopback listeners and true otherwise.
WARDEN_TRUST_PROXYfalseReserved proxy-trust setting; forwarded client identity is not implicitly trusted.

Password setup

go build -o warden ./cmd/warden
./warden hash-password 'choose-a-strong-password'
export WARDEN_PASSWORD_HASH='pbkdf2-sha256$...'
./warden

Warden does not ship with a cleartext default password.

Frontend build

nift build

Authoritative website/app frontend files live under content/ and templates/; public/ is generated output.

Know the boundary

Powerful by design.
Not Internet-ready by implication.

Warden already has real authentication, CSRF protection, filesystem confinement, WebSocket origin checks, security headers and audit logging. It also exposes a PTY and privileged administration. The current build is for local/private dogfooding while the planned adversarial security campaign is still outstanding.

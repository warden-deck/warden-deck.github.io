Know the boundary

Powerful by design.
Not a sandbox by implication.

Warden has server-side accounts, roles and capabilities, TOTP, encrypted secrets, CSRF protection, local-proxy hardening, WebSocket origin checks and SQLite audit history. Terminal and Agent access still execute with the Warden process user's OS authority.
